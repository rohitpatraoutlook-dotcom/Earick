# Earick ⚛️

A lightweight **multi-book physics RAG chatbot** that runs entirely on an Android phone via Termux.

Ask physics questions and get grounded answers with page citations from:

- 📘 **University Physics with Modern Physics** — Young & Freedman (13th ed.)
- 📗 **General Relativity: An Introduction for Physicists** — Hobson, Efstathiou & Lasenby
